# Delta Force Tactical Map · 指挥官三维战术板

在线版：<https://minecraforever.github.io/delta-force-tactical-map/>

在线版仅保留低精度，无法实现中高精度；如需体验，请联系作者获取本地版。

本次从 2026-11-12 最新完整版同步网页功能、低精度地图、地形和事件数据。地图：攀升、烬区、临界点、贯穿、刀锋、堑壕战、断轨、风暴眼、断层、摩格旧城区、天际港。

为符合 GitHub Pages 站点大小限制，按既定顺序未纳入克劳狄斗兽场、余震和金字塔；乌姆斯运河已随赛季轮换归档。较大的低精度 MFPK 按原有方式分块，页面按顺序拼接。

macOS 双击 `start-mac.command`；Windows 双击 `start-windows.cmd`。本地静态文件服务器只监听 127.0.0.1。

网页代码与启动脚本采用 MIT 许可证；游戏模型、贴图和地图数据不在此许可证范围内。

## 本地版自动更新

完整版与深大校队专用版由作者通过网盘分发。每版现提供完整包，以及可解压到同一目录的轻量程序包和地图捆绑包。两个分支使用 `updates/stable.json` 中相互隔离的更新通道；1.7 用户可自动更新网页和小型配置，地图资源另从作者网盘获取。2026-11-03 发布的完整版 1.5／深大版 1.6 可先使用作者提供的前端桥接升级包。Windows 会检查独立 Python 运行时；Mac 会建立独立环境。离线时继续运行已安装版本。

`updates/build_incremental_release.py` 是在 VS Code 运行的增量制作脚本。日常增量只更新前端代码及小型配置，不传送地图包或逐地图数据；地图资产变化由作者通过网盘分发完整包。先提交并核对仓库 `updates/assets/` 中的小型附件，最后更新 `updates/stable.json`；启动器与运行时升级也需重新分发完整 ZIP。网页 Pages 版仍只提供低精度地图。
