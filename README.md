# Delta Force Tactical Map · 指挥官三维战术板

在线版：<https://minecraforever.github.io/delta-force-tactical-map/>

在线版预装低精度；高精度数据包不托管。点击高精度按钮，可在浏览器中选择作者提供的当前地图 `_high.mfpk` 文件加载。

导入的高精度文件只在当前页面会话中使用，刷新后需重新选择；该功能不会把文件上传到 GitHub。

本次从 2026-11-15 最新完整版同步网页功能、低精度地图、地形和事件数据。地图：攀升、烬区、临界点、贯穿、刀锋、堑壕战、断轨、风暴眼、摩格旧城区、天际港。

为符合 GitHub Pages 站点大小限制，按既定顺序未纳入克劳狄斗兽场、余震、金字塔和断层；乌姆斯运河已随赛季轮换归档。在线版地表使用标准贴图；完整的高清地表贴图保留在本地版。较大的低精度 MFPK 按原有方式分块；新增或更新的大地图包采用 4 MiB 分块，页面按顺序拼接。

macOS 双击 `start-mac.command`；Windows 双击 `start-windows.cmd`。本地静态文件服务器只监听 127.0.0.1。

网页代码与启动脚本采用 MIT 许可证；游戏模型、贴图和地图数据不在此许可证范围内。
